# Controle Financeiro Pessoal

Aplicação web feita com React + Vite para gestão financeira pessoal sem planilhas.

## Funcionalidades

- Geração automática de usuário e senha para novas contas.
- Login com credenciais exclusivas.
- Dashboard com:
  - receitas totais,
  - despesas fixas,
  - despesas variáveis,
  - saldo atual (sobrando/faltando no caixa).
- Resumo de gastos recorrentes com categoria.
- Ranking de maiores gastos por categoria.
- Cadastro de novas movimentações (receita/despesa).
- Interface moderna com paleta neutra baseada em variáveis CSS (`:root`) para fácil customização.

## Como rodar

```bash
npm install
npm run dev
```

Para build de produção:

```bash
npm run build
npm run preview
```
